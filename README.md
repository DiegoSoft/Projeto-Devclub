Projeto DevClub

Landing page institucional desenvolvida com React + Vite, com uma identidade visual editorial, moderna e marcante. O projeto utiliza animações com GSAP e componentes visuais para apresentar formações, plataforma, projetos, professores, depoimentos, FAQ e footer.

Este projeto foi desenvolvido exclusivamente para estudo e prática, com o objetivo de aprofundar meus conhecimentos em React, Vite, GSAP, Tailwind CSS e desenvolvimento de interfaces modernas.

Inspiração e migração

Este projeto foi inspirado no Bonfire BBQ, desenvolvido originalmente com Astro.

Como parte do meu processo de aprendizagem, realizei a migração completa da estrutura e dos componentes para React.js, preservando a proposta visual e adaptando a implementação para o ecossistema React.

Deploy na Vercel

Configuração recomendada:

Framework Preset: Vite

Install Command: npm install

Build Command: npm run build

Output Directory: dist
