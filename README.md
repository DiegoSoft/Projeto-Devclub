## ✨ Sobre o projeto

O **Projeto DevClub** é uma landing page desenvolvida com React e Vite. A interface combina componentes visuais e animações com GSAP para apresentar formações, plataforma, projetos, professores, depoimentos, FAQ e rodapé.

Este projeto foi criado exclusivamente para estudo e prática, com foco no aprimoramento de conhecimentos em React, Vite, GSAP, Tailwind CSS e desenvolvimento de interfaces modernas.

---

## 💡 Inspiração e migração

O projeto foi inspirado no [Bonfire BBQ](https://github.com/GaseousIce/bonfire-bbq), originalmente desenvolvido com Astro.

Como parte do processo de aprendizagem, a estrutura e os componentes foram migrados para **React.js**, preservando a proposta visual e adaptando a implementação ao ecossistema React.

---

## 🛠️ Tecnologias

- **React** — construção da interface.
- **Vite** — ambiente de desenvolvimento e build.
- **GSAP** — animações e interações visuais.
- **Tailwind CSS** e **CSS customizado** — estilização da aplicação.

---

## 🚀 Rodando localmente

Instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

---

## ✅ Validação antes do deploy

```bash
npm run lint
npm run build
```

---

## 👀 Preview da versão de produção

```bash
npm run preview
```

---

## ▲ Deploy na Vercel

Use a seguinte configuração no painel da Vercel:

| Configuração | Valor |
| --- | --- |
| Framework Preset | `Vite` |
| Install Command | `npm install` |
| Build Command | `npm run build` |
| Output Directory | `dist` |

O arquivo `vercel.json` já está configurado para redirecionar as rotas internas para `index.html`.
